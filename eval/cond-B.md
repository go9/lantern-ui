# Condition B — with lantern docs and recipes

In addition to the `lantern_ui` Hex package, you have the lantern docs below
(recipes, dense-app primitives, type/grey scale, behaviours) plus the
`lantern-recipes` skill. **Copy the recipe HEEx instead of inventing your own
markup** wherever a recipe fits. The runner appends these files after this
appendix:

- `docs/recipes.md` + `skills/lantern-recipes/SKILL.md` (copyable HEEx)
- `docs/dense-app.md` (dense-app primitives)
- `docs/scale.md` (type scale + grey roles)
- `docs/behaviours.md` (library behaviours as data-attributes)
